# agustinoberg

Monorepo for agustín oberg's personal brand (product designer). Turborepo + pnpm. **English is the primary language everywhere; Spanish is a translation.**

```
apps/design/        design language site (English at /, Spanish at /es/)   → `pnpm dev:design`
                    deployed to Cloudflare Pages by .github/workflows/deploy-design.yml
apps/portfolio/     portfolio, Astro (English at /, Spanish at /es/)   → `pnpm dev:portfolio`
                    deployed to Cloudflare Pages by .github/workflows/deploy-portfolio.yml
                    every fact and string lives in src/data/content.ts (en + es)
packages/brand/     @agustinoberg/brand: the spec (brand.md = English, brand.es.md = Spanish) and tokens (tokens.css, tokens.json)
packages/skills/    agent skills for skills.sh: agustinoberg-design, agustinoberg-product   → `pnpm sync:skills`
skills.sh.json      tells `npx skills` to look in packages/skills/skills
```

More apps will come (portfolio…). Each new app goes in `apps/<name>` and depends on `@agustinoberg/brand`. Each new skill goes in `packages/skills/skills/agustinoberg-<area>` (see `packages/skills/README.md`).

## Before any design or UI work

- Use the skills in `packages/skills/skills`:
  - `agustinoberg-design` for what the design is.
  - `agustinoberg-product` for building a product. With it, references lead when they exist, and my touch is layered on top.
- The source of truth is `packages/brand/brand.md`: philosophy, decisions, if/then rules, light and dark mode, micro-blurs, motion and voice.
- Import `@agustinoberg/brand/tokens.css` (or read `tokens.json`) for every value. Don't hardcode colors, radii, blurs or timings that exist as tokens.
- Build light and dark mode together, and respect `prefers-reduced-motion`.
- Never invent projects, clients, metrics or copy about me. Ask, or leave `[TODO]` placeholders.

## Keeping things in sync

- When a rule changes, update `brand.md` (English) and `brand.es.md` (Spanish) in the same change. When a page changes, update `apps/design/index.html` and `apps/design/es/index.html` together. If they differ, English wins.
- After changing `packages/brand`, run `pnpm sync:skills`. Skill files with a "Generated from" header come from the brand package; never edit them by hand.
- The design site's AI files (`llms.txt`, `llms-full.txt`, `brand.md`, `brand.es.md`, `tokens.*`, `robots.txt`, `sitemap.xml`) are generated by `apps/design/vite.config.js`. Don't copy them by hand.
- The public URL lives in one place: `VITE_SITE_URL` in `apps/design/.env` (now `https://agustinoberg-design.pages.dev`, later `https://design.agustinoberg.com`). In CI, the GitHub repo variable `SITE_URL` overrides it.

## Commands

```sh
pnpm install
pnpm dev:design        # http://localhost:5173/  (es: /es/)
pnpm dev:portfolio     # http://localhost:4321/  (es: /es/)
pnpm build             # every app and package
pnpm sync:skills       # regenerate + validate the skills
```

## Deploy

- Push to `main`: GitHub Actions builds `apps/design` and deploys it to Cloudflare Pages (project `agustinoberg-design`). Pull requests get preview URLs.
- Same for `apps/portfolio` (project `agustinoberg` → https://agustinoberg.pages.dev, workflow `deploy-portfolio.yml`). Its URL is `PUBLIC_SITE_URL` in `apps/portfolio/.env`; the repo variable `PORTFOLIO_SITE_URL` overrides it in CI.
- Needs repo secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`. Without them, CI builds and skips the deploy.
- Don't deploy by hand or to anywhere else unless I ask.
